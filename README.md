# 🏙️ Skyline Properties - Premium Real Estate Landing Page

A fully responsive, pixel-perfect implementation of a modern luxury real estate website UI. This project replicates a premium, high-end real estate agency landing page with a focus on clean typography, elegant spacing, and a professional color palette.

## ✨ Features

*   **Sticky Navigation Bar:** Clean header with logo, links, and a call-to-action contact button.
*   **Hero Section:** High-quality background image with a prominent headline, call-to-action buttons, and a glassmorphism floating search bar (Location, Type, Budget, Size).
*   **Trust Indicators:** Highlighted stats (500+ Luxury Properties, Verified Agents, Best Market Price, Fast Closing).
*   **Signature Properties:** A visually appealing grid of property cards with hover effects, pricing, and key details (beds, baths, sqft, floor).
*   **Prime Locations:** A quick-view grid of popular neighborhoods with image overlays.
*   **Promo Banner:** A striking call-to-action for "Zero Agent Fees" with a custom blue overlay.
*   **How It Works (4 Steps):** A clean step-by-step process diagram.
*   **Elite Agents:** Professional profile cards for real estate agents with contact and rating details.
*   **Testimonials:** Customer reviews with avatars and star ratings.
*   **Footer CTA & Newsletter:** Engaging call-to-action section with a subscription form and social media links.
*   **Responsive Design:** Optimized for desktop, tablet, and mobile viewing.

## 🛠️ Technologies Used

*   **HTML5:** Semantic structure.
*   **Tailwind CSS (via CDN):** For rapid, utility-first styling and responsive design.
*   **Font Awesome (via CDN):** For scalable vector icons.
*   **Google Fonts:** 'Inter' font family for modern, clean typography.

## 🚀 How to Use

1.  Clone this repository or download the source code.
2.  Ensure the main file is named `index.html`.
3.  Double-click `index.html` to open it in any modern web browser.
4.  No build tools, Node.js, or local server are required.
